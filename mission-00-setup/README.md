## 3. Commands / tools used
- `python3 --version` — Checks whether Python 3 is installed and shows its exact version (`Python 3.9.6`).
- `git --version` — Checks whether Git is installed and shows its exact version (`git version 2.55.0`).
- `mkdir -p` — Creates nested folders cleanly in a single command.
- `touch` — Creates empty placeholder Markdown and Python files inside each mission folder.
- `git init -b main` — Initializes a new local Git repository with `main` as the default branch.
- `find . -maxdepth 2` — Verifies the folder and file hierarchy after setup.

## 4. My understanding
A repository is a central project folder tracked by a version control system (Git) and optionally hosted online (such as on GitHub) so every change, file addition, and milestone is recorded over time. Organizing the assignment by mission keeps notes, code, and privacy-safe evidence cleanly separated, makes it easy to commit one mission at a time, and helps any reviewer navigate directly to each topic.
