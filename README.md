# Digita-Detective-8529 — The Digital Detective

This repository contains my work for the **Diwali Independent Learning Assignment: The Digital Detective**. Throughout this project, I investigate how a computer works, practise Terminal commands, explore operating system concepts, run Python programs, convert number systems, collaborate using Git and GitHub, and examine how computers communicate over networks.

Each mission is completed in sequence, documented in its own folder, and committed separately with a clear commit message.

## My Learning

- **How computers process and store data:** Through IPOS and number systems, I learned how everyday actions turn into binary (`0` and `1`) data processed by the CPU/RAM and stored on an SSD.
- **Command-line & operating system awareness:** Using Terminal commands (`pwd`, `ls -lah`, pipes, `ps`, `df -h`) showed me how the OS tracks processes, disk space, and permissions.
- **Version control discipline:** Committing one mission at a time keeps history clean and makes it easy to test changes safely on separate branches before merging.
