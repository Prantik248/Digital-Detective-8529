## Topics Explored

- **Computer Fundamentals:** Input, Processing, Output, Storage (IPOS), hardware components, OS/application/utility software, and everyday embedded systems.
- **Command-Line Interface:** Directory navigation, safe file creation/copying/renaming, output redirection (`>` vs `>>`), flags, pipes (`|`), and package managers (Homebrew).
- **Operating Systems:** System details, disk capacity, running processes and PIDs, absolute vs relative paths, and `r`/`w`/`x` file permissions.
- **Program Execution:** Running Python 3 scripts (`hello.py`) and comparing compilers vs interpreters.
- **Data Representation:** Manual decimal/binary/hexadecimal conversions, Python verification, building `number_converter.py`, and ASCII/UTF-8 encoding.
- **Version Control:** Git staging vs committing, branch workflows (`update-about`), Pull Requests, and a personal Git command glossary.
- **Networking:** LAN/MAN/WAN, DNS, routers, protocols, packet switching, client-server communication, and `ping`/`nslookup`/`curl` diagnostics.

## How to Run the Number Converter

From the root of the repository in Terminal, navigate into the Mission 5 folder and run `number_converter.py` with Python 3:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

Enter any whole decimal number when prompted (for example `13`, `42`, or `255`) to view its binary and hexadecimal equivalents.

## Summary of What I Learned

Completing these missions connected the whole picture of modern computing: physical hardware relies on an operating system to manage processes, storage, and permissions; programs and data reduce to binary bits and character encodings; Terminal and Git let developers work cleanly and track every change; and layered network protocols let a browser resolve a domain name and fetch a webpage across the globe in milliseconds.
